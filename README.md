# SOC Detection Engineering with Splunk & Sysmon

## Overview
This repository documents my hands-on learning journey in SOC detection engineering using Splunk and Windows Sysmon. The focus is on understanding Windows telemetry, building meaningful detections, reducing false positives, and correlating attack behavior as done in real SOC environments.

## Current Status
This project is being built incrementally. Initial focus is on documenting detection logic and SOC reasoning before expanding into full SPL queries and case studies.

## Tools Used
- Splunk Enterprise
- Splunk Universal Forwarder
- Windows Sysmon

## Learning Focus
- Understanding process execution (Image, ParentImage, CommandLine)
- Writing alert-worthy detections
- False positive reduction
- Correlation of multi-stage attacks
- SOC-style investigation and response reasoning
